# Mahadev Society — Capacitor Android App

This folder wraps the existing `sacco-frontend` web app into an Android APK using Capacitor.

## ⚠️ Important
- **Do NOT edit** `../sacco-frontend/` source files from here
- **Do NOT edit** `../sacco-mobile/` React Native app
- This is an independent Capacitor wrapper only

---

## Folder Structure
```
sacco-capacitor/
├── android/              ← Android Studio project (auto-generated by Capacitor)
├── node_modules/         ← Capacitor CLI & plugins
├── capacitor.config.json ← Main Capacitor configuration
├── package.json
├── build-and-sync.bat    ← One-click build script (Windows)
└── README.md
```

## Setup Requirements

### Prerequisites
1. **Android Studio** — https://developer.android.com/studio
2. **JDK 17+** — Included with Android Studio
3. **Android SDK** — API 24+ (Android 7.0)

---

## How to Build APK

### Option 1 — Use the batch script (Easiest)
```bash
build-and-sync.bat
```
Then open Android Studio → Build → Generate Signed APK

### Option 2 — Manual steps
```bash
# 1. Build the web app (production)
cd ../sacco-frontend
npm run build

# 2. Sync web assets into Android project
cd ../sacco-capacitor
npx cap sync android

# 3. Open in Android Studio
npx cap open android
```
Then in Android Studio: **Build → Generate Signed Bundle / APK → APK**

---

## Development (Live Reload from local server)

For testing with your local backend + live reload, edit `capacitor.config.json`:
```json
"server": {
  "url": "http://192.168.X.X:3000",
  "cleartext": true
}
```
Replace `192.168.X.X` with your PC's local IP address. Then `npx cap sync android`.

---

## Backend URLs
- **Production**: `https://sacco-management-web-app.onrender.com` (auto-used in `npm run build`)
- **Development**: `http://localhost:5000` (via localtunnel or local IP)

The `sacco-frontend/.env.production` file controls the production API URL.
